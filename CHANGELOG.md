# SAP GUI Connector

## [Customer & System Type] - {PR_MERGE_DATE}

- Added a **customer name** and **system type** (E/Q/P) to each system.
- Systems are now grouped by customer in the list, menu bar, and quick connect.
- "Connect to SAP System" is now a searchable list — type a customer name to
  filter live, then narrow by E/Q/P and connect. Existing systems are migrated
  automatically (defaulting to type P, no customer) and can be edited afterwards.
